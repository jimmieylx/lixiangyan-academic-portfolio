# Lixiang Yan Academic Portfolio

Static personal academic portfolio for Dr Lixiang Yan, hosted as a GitHub Pages project site using HTML, CSS and JavaScript.

## Featured research resource

**Agentivism — A Learning Theory for the Age of Artificial Intelligence**:
https://jimmieylx.github.io/lixiangyan-academic-portfolio/agentivism/

The companion website explains the four mechanisms and six empirical propositions proposed in Yan and Gašević (2026), *Computers and Education: Artificial Intelligence*, 11, 100684. Journal article: https://doi.org/10.1016/j.caeai.2026.100684

Source: [agentivism/](agentivism/)

## Files

\`index.html\` and \`styles.css\` provide the academic homepage. \`agentivism/\` contains the theory companion page. \`sitemap.xml\` lists both public URLs.
